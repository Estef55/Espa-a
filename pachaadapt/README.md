# PACHAADAPT by YACHAY

Estructura inicial del proyecto conforme al árbol acordado. Los módulos contienen únicamente esqueletos y tareas pendientes; no representan una aplicación completa.

## Componentes
- `frontend/`: interfaz web y PWA.
- `backend/`: API y lógica del servidor.
- `ai/`: procesamiento, adaptaciones, asistente y análisis.
- `database/`: esquema, migraciones y datos de demostración.
- `storage/`: archivos persistentes.
- `tests/`: pruebas por categoría.
- `docs/`: arquitectura, funcionamiento e investigación de campo.
- `scripts/`: preparación, arranque, copias e importación.

Antes de fijar flujos curriculares, idiomas/variedades y nivel piloto, realizar la investigación de campo.
